Памятка кассира ​

Распечатайте эту страницу и положите рядом с кассой

В разделе Скачать PDF есть «Памятка кассира» — один лист A4.

1. Как открыть программу ​

Зелёный значок Kassa на рабочем столе → выберите своё имя → пароль → Войти.

2. Продажа ​

  1. Отсканируйте штрихкод товара — товар попадает в корзину (звук «бип»). Если отсканировать тот же товар ещё раз, количество увеличится.
  2. Если штрихкода нет — введите название в поле сверху и выберите товар из списка.
  3. Весовой товар (кг) — введите вес, напр. 0,750.
  4. Изменить количество: − / +. Ошибочный товар удалите кнопкой ✕.

3. Оплата ​

КнопкаКогда
Наличные или F2Введите сумму, которую дал покупатель (или кнопки 5 ₼, 10 ₼…). Программа покажет сдачу. Если сумма без сдачи — оставьте поле пустым.
Карта или F3Сначала убедитесь, что оплата на банковском терминале прошла, потом подтвердите.

Затем Завершить продажу или Enter.

4. Чек ​

  • Если подключён принтер чеков, чек печатается сам.
  • Если нет — после продажи нажмите кнопку «Чек» в зелёной надписи.

5. Звуки ​

ЗвукЧто значит
Короткий «бип»Товар найден
Низкий звукТовар не найден — админ должен добавить товар в систему

6. Как закрыть ​

✕ в правом верхнем углу окна. Программа сама сделает бэкап и закроется. Если долго ничего не нажимать, программа выйдет из вашей учётной записи — введите пароль снова.

Если что-то не получается ​

  • Белый экран / «ошибка» — Перезагрузить или закройте окно и откройте снова. Продажи не пропадут.
  • Забыли пароль — админ меняет его в разделе «Пользователи».
  • Всё остальное — Если что-то не получается.

Установка и первый запуск ​

Эта страница — для того, кто устанавливает программу (обычно владелец магазина). Делается один раз.

1. Скачать программу ​

Последняя версия: Kassa-Setup — скачать (файл Kassa-Setup-….exe).

2. Установить ​

  1. Откройте файл Kassa-Setup-….exe.
  2. Если Windows пишет «неизвестная программа»: «Подробнее» → «Выполнить в любом случае».
  3. Выберите язык (Azərbaycanca, Русский, English).
  4. Выберите вариант установки:
    • «Установить для всех пользователей» (рекомендуется для магазина) — Windows спросит пароль администратора. Программа работает в защищённом режиме: кассир не может удалить программу и данные. См. Учётные записи Windows.
    • «Установить только для меня» — пароль администратора не нужен. Для пробы или домашнего компьютера.
  5. Далее → Установить → Завершить. На рабочем столе появится зелёный значок Kassa.

3. Первый запуск ​

  1. Пароль установки — получите его у того, кто дал вам программу. Спрашивается только в первый раз.
  2. Выберите язык, введите название магазина, своё имя и пароль (не менее 8 символов, буквы и цифры). Вы становитесь админом магазина.
  3. Установить.

4. Код восстановления — обязательно запишите на бумаге ​

После установки на экране появится код восстановления.

  • Запишите его на бумаге и храните дома или в сейфе. Не храните его файлом на компьютере.
  • Если компьютер сломается или его украдут, вернуть данные можно только с этим кодом.
  • Посмотреть его можно и позже: Бэкап → Код восстановления → ваш пароль.

Поставьте галочку «Я записал код…» → Продолжить.

5. Учётные записи Windows: отдельная запись для кассира ​

Самая надёжная защита (при установке «Для всех пользователей»):

  1. Для владельца — учётная запись Windows администратора с паролем. С неё Kassa устанавливают и обновляют.
  2. Для кассира — стандартная учётная запись (не администратор): Параметры → Учётные записи → Другие пользователи → Добавить учётную запись → тип учётной записи «Стандартный пользователь».
  3. Каждый день компьютер работает под учётной записью кассира. Kassa работает и там, но кассир не может удалить или изменить программу и файлы данных.
  4. В Kassa каждый входит под своим именем и паролем Kassa (они не связаны с паролем Windows).

В этом режиме закрытие окна не останавливает программу полностью — она работает в фоне (отчёт в Telegram, бэкап). Это нормально.

Как работает сканер

Сканер штрихкодов работает как клавиатура: очень быстро «печатает» цифры и в конце нажимает Enter. Программа отличает его от человека по скорости, поэтому при сканировании никуда нажимать не нужно.

Продажа ​

Добавить товар в корзину ​

  • Отсканируйте — товар попадает в корзину, звучит короткий «бип». Если отсканировать тот же товар ещё раз, количество увеличится.
  • Если штрихкода нет — введите название в поле сверху и выберите товар из списка.
  • Весовой товар (кг) — программа спросит вес: напр. 0,750 (750 грамм).

Низкий звук и «Товар не найден» — этого товара нет в системе. Админ должен его добавить. Если сканирует сам админ, сразу откроется окно «Новый товар».

Исправить корзину ​

  • Изменить количество: − / + или нажмите на число.
  • Удалить ошибочный товар: ✕ в конце строки.
  • Удалить всё: Очистить корзину.

Оплата ​

Наличные (F2)Введите сумму, которую дал покупатель, или выберите готовую кнопку. Программа покажет сдачу. Если сумма без сдачи — оставьте поле пустым.
Карта (F3)Сначала убедитесь, что оплата на банковском терминале прошла, потом подтвердите.

Завершить продажу или Enter. На экране появится надпись «Продажа №… — … ₼».

Чек ​

  • Если принтер чеков выбран и включено «Печатать чек автоматически после продажи» — чек печатается сам.
  • Если нет — кнопка «Чек» в зелёной надписи.
  • Чек старой продажи: Продажи → продажа → Печать чека.
  • При продаже за наличные денежный ящик (если подключён) открывается сам.

Если остаток ушёл в минус

Если продано больше, чем есть в системе, продажа всё равно проходит, но появляется предупреждение — значит, приёмка товара не сделана. Админ должен сделать приёмку товара.

Товары, штрихкоды и этикетки ​

Только админ.

Новый товар ​

Товары → Новый товар:

ПолеЧто вводить
ШтрихкодОтсканируйте штрихкод товара
НазваниеНазвание, которое увидят кассир и покупатель в чеке
Ед. изм.Штука или Килограмм (весовой)
Цена продажиЦена, которую платит покупатель
Закупочная ценаЦена, по которой купили вы (для расчёта прибыли; кассир её не видит)
Минимальный остатокЕсли осталось меньше — предупреждение «Мало»

Если при продаже или приёмке отсканирован штрихкод, которого нет в системе, это окно откроется само.

Товар без штрихкода ​

Хлеб, зелень, своя продукция: кнопка Создать штрихкод → программа выдаёт штрихкод магазина (начинается с 29). Затем распечатайте этикетку и наклейте на товар.

Изменить цену ​

В строке товара ✏️ → новая цена → Сохранить. Изменение записывается в журнал. Снять товар с продажи: уберите галочку Активен (товар не удаляется, история остаётся).

Печать этикеток ​

  1. Товары → отметьте галочками нужные товары (или 🏷 в строке одного товара).
  2. Печать этикеток → вид:
    • Лист A4 — 24 этикетки (70×37 мм) или 40 этикеток;
    • рулон принтера этикеток — 58×40, 50×30, 40×30 или 30×20 мм (размер этикетки в рулоне).
  3. Сколько штук каждого товара: +.
  4. Печать. Если выбран принтер этикеток, на кнопке написано имя принтера — этикетки печатаются без окна печати.

Через окно печати (если принтер не выбран), в первый раз

Выберите Масштаб: 100% (фактический размер) и Поля: Нет. Сначала сделайте пробную печать на обычной бумаге.

Когда этикетка напечатана, проверьте её штрихкод сканером — должен быть «бип».

Приёмка товара ​

Только админ. Чтобы увеличить остаток, когда пришёл товар.

  1. Раздел Приёмка → отсканируйте поступивший товар (или введите название).
  2. Для каждого товара введите количество и закупочную цену.
  3. По желанию введите поставщика и примечание.
  4. Подтвердить приёмку → Подтвердить.

Остаток сразу растёт. Если отсканирован товар, которого нет в системе, откроется окно «Новый товар».

Документ приёмки ​

Откройте приёмку в списке «Приёмки за последние 30 дней» внизу → Печать документа (с местами для подписей — поставщика и принявшего).

Если приёмка сделана с ошибкой

Приёмка не удаляется (чтобы не нарушить историю склада). Чтобы исправить количество, добавьте разницу новой приёмкой; если записано лишнее — обратитесь к техническому специалисту.

Остатки и отчёт ​

Остатки ​

Сколько осталось каждого товара. Вкладка Мало — распечатайте как лист заказа.

Отчёт (админ) ​

За выбранные дни: выручка, прибыль, наличные и карта, самые продаваемые, заканчивающиеся товары.

«Наличные» — деньги, которые должны быть в кассе. В конце дня пересчитайте кассу и сравните.

Печать и Excel ​

На каждой странице:

  • Печать — на принтер или «Сохранить как PDF»;
  • Excel — файл сохраняется в папку «Загрузки».

Если список очень длинный, на экране видны первые 300 строк — внизу «Показать ещё …». В печать и Excel попадает всё.

Продажи и отмена ​

  • Продажи → выберите дату → нажмите на продажу → подробности.
  • Печать чека — чек старой продажи.
  • Кассир видит только свои продажи.

Отменить продажу (только админ) ​

Ошибочная продажа → Отменить продажу → укажите причину (обязательно).

  • Продажа не удаляется — остаётся как «Отменена», записывается, кто и когда её отменил.
  • Товары возвращаются в остаток.
  • В ежедневном отчёте в Telegram отмены показаны отдельно.

Пользователи ​

Только админ.

Новый пользователь ​

Новый пользователь → имя, роль, пароль.

РольЧто можетПароль
КассирПродажа, просмотр остатков и своих продажне менее 4 символов (напр. 4 цифры)
АдминВсё: товары, цены, приёмка, отмена, отчёт, пользователи, настройкине менее 8 символов, буквы и цифры

Пароль ​

  • Если кто-то забыл пароль, админ задаёт новый кнопкой Пароль.
  • Каждый может сменить свой пароль: нажмите на своё имя слева внизу → Сменить пароль.

Блокировка ​

Если кто-то 10 раз ввёл неверный пароль, нужно подождать 1 минуту (после 3-й ошибки видно, сколько попыток осталось). Админ может снять блокировку сразу кнопкой Разблокировать. Количество и время можно изменить в Настройках.

Сотрудник уволился ​

Отключить — пользователь не удаляется, его прошлые продажи остаются, но войти он не может.

Режим обучения: обучить нового кассира ​

Помощь → Режим обучения (кассир учится) → длительность (15 мин.–2 часа) → Начать обучение.

  • Экран продажи работает полностью: сканирование, наличные/карта, сдача. Но продажи не записываются и остатки не меняются.
  • На всех экранах видна оранжевая полоса «РЕЖИМ ОБУЧЕНИЯ» и оставшееся время.
  • В это время настоящие продажи невозможны — обучайте, когда нет покупателей.
  • По истечении времени режим выключается сам; закончить раньше — Завершить обучение.
  • Включить может только админ (не кассир). Включение и выключение записываются в журнал и в ежедневный отчёт Telegram.

Настройки и язык ​

Только админ. После изменений нажмите кнопку Сохранить вверху (кроме токена и чата Telegram — они сохраняются сами). Каждое изменение записывается в журнал.

У каждого свой язык ​

Нажмите на своё имя слева внизу → Язык → Azərbaycanca / Русский / English (или «Язык магазина»). Меняется только для вас — кассир может выбрать свой язык отдельно.

Принтер чеков и этикеток ​

Один термопринтер (напр. Xprinter XP-365B) может печатать и чеки, и этикетки со штрихкодом.

Подключение ​

  1. Подключите принтер по USB и установите его драйвер для Windows (диск из коробки или сайт производителя). Принтер должен появиться в списке «Принтеры» Windows.
  2. Kassa → Настройки → Принтеры:
    • Принтер чеков и Принтер этикеток (штрихкодов) — выберите устройство из списка (можно одно и то же);
    • Размер этикетки (в карточке «Продажа и печать») — размер этикетки в рулоне (напр. 40×30);
    • по желанию: Печатать чек автоматически после продажи, Открывать денежный ящик при оплате наличными.
  3. Сохранить → Пробный чек и Пробная этикетка.
  4. Считайте штрихкод пробной этикетки сканером — должен быть «бип».

Как это работает ​

  • Если принтер выбран — чек и этикетка печатаются сразу, без окна печати.
  • Если принтер не выбран («Окно печати») — при каждой печати открывается окно печати Windows, работает с любым принтером.
  • Если принтер выключен или закончилась бумага — появится ошибка и предложение «Через окно печати». Чек не пропадает.

Проблемы ​

ПризнакЧто делать

Этикетка печатается на двух этикетках / остаётся пустое место«Размер этикетки» должен совпадать с рулоном. Откалибруйте датчик принтера (Xprinter: включите, удерживая кнопку FEED).

Telegram: ежедневный отчёт и бэкап ​

Каждый вечер на телефон владельца приходит краткий отчёт (продажи, выручка, наличные и карта, отмены — кто сделал, заканчивающиеся товары) и зашифрованный бэкап. Даже если компьютер украдут или он сломается, копия в Telegram останется.

Если сообщение не пришло — это уже предупреждение: что-то не так.

Подключение (один раз, нужен интернет) ​

  1. В Telegram на телефоне найдите @BotFather → /newbot → дайте боту название (напр. «Mağaza Kassa») и имя пользователя (должно заканчиваться на bot).
  2. BotFather выдаст длинный токен (123456789:AA…). Скопируйте его.
  3. Kassa → Настройки → Telegram → вставьте в поле Токен бота.
  4. Найдите своего бота в Telegram и напишите ему /start.
    • Чтобы отправлять в группу: добавьте бота в группу и напишите в группе /start@имя_бота (напр. /start@magaza_kassa_bot). Обычного сообщения недостаточно — Telegram не показывает боту обычные сообщения группы.
  5. В Kassa нажмите Найти чат. Если найдено несколько чатов (личный и группа) — выберите из списка. Выбор сохраняется сам.
  6. Выберите время отчёта (напр. 21:00) → Тестовое сообщение. На телефон должно прийти сообщение.

Дальше ​

  • Отчёт приходит каждый день в выбранное время. Если программа была закрыта до этого времени — на следующий день приходит «запоздалый отчёт».
  • Бэкап — раз в день. При большой базе файл делится на части (.001, .002…).
  • Если интернета нет — повторная попытка каждые 15 минут. Время и результат последней отправки видны в Настройках.
  • Сохранённый токен на экране не показывается (поле пустое, написано «Сохранён»). Если кто-то узнал токен — /revoke в BotFather.

Жёлтое предупреждение «Бэкап в Telegram не отправляется»

Уже больше 2 дней ничего не удаётся отправить. Причина написана в предупреждении. Проверьте: есть интернет? Бот не удалён? Настройки → Telegram → Тестовое сообщение.

Как восстановить бэкап из Telegram: Бэкап и восстановление.

Бэкап и восстановление ​

Программа сама делает бэкап ​

  • Регулярно (обычно раз в 20 часов) и при закрытии.
  • Отдельный бэкап перед обновлением и перед восстановлением.
  • Если подключён Telegram — раз в день на телефон.

Раз в неделю: USB ​

Вставьте USB-флешку → Бэкап → Скопировать последний бэкап на диск …. Не храните флешку рядом с компьютером.

Код восстановления ​

Бэкап → Код восстановления → ваш пароль. Его нужно записать на бумаге — если компьютер сломается, без него данные не вернуть.

Восстановить бэкап ​

Если что-то случайно испортилось:

  • в списке рядом с бэкапом Восстановить → пароль админа.

Восстановление из файла ​

Файл с USB или скачанный из Telegram: Восстановить из файла → выберите файл → пароль админа.

  • Если из Telegram пришли части (.001, .002…) — скачайте все и выберите все вместе (с Ctrl).
  • Если файл с другого компьютера — введите и код восстановления той установки.

После восстановления все входят заново. Состояние до восстановления остаётся как бэкап «Перед восстановлением» — ничего не теряется.

Экран восстановления ​

Если база удалена, повреждена, потерян ключ или осталась старая версия программы, вместо обычного экрана открывается экран Восстановление. Причина написана вверху.

  1. Введите код восстановления (с бумаги).
  2. Выберите: Восстановить этот бэкап, Восстановить из файла (USB, Telegram), Восстановить ключ или Проверить снова.
  3. Начать с пустой базы — только если бэкапов нет совсем.

Без кода восстановления на этом экране ничего сделать нельзя — данные защищены. Если написано «Старая версия программы» — просто установите последнюю версию.

«ВНИМАНИЕ: база заменена старой копией!» ​

Пока программа была закрыта, кто-то заменил файл данных старой копией — продажи за это время могли пропасть. Проверьте бэкапы в Telegram и на USB, при необходимости восстановите более новый, затем Понятно.

Компьютер сломался ​

Установите Kassa на новом компьютере → при первом запуске создайте временного админа → Бэкап → Восстановить из файла (файл с USB или из Telegram) + код восстановления старой установки. Старые пользователи, товары и настройки вернутся.

Обновление ​

Программа принимает только официальные (подписанные) обновления Kassa — поддельный или изменённый файл не будет установлен.

Через интернет ​

Когда выходит новая версия, админ видит надпись «Доступна новая версия Кассы» → Открыть (или Настройки → Обновление) → Обновить → пароль админа.

Программа сначала делает бэкап, закрывается и через несколько секунд сама открывается в новой версии. Посреди продажи ничего не устанавливается само — только когда вы нажмёте «Обновить».

Из файла (если нет интернета) ​

Скопируйте на компьютер файл Kassa-Update-….kassa, который прислал разработчик (USB, WhatsApp) → Настройки → Обновление → Обновить из файла (.kassa) → выберите файл → «Файл проверен: официальная Касса …» → Обновить.

Потом ​

Один раз появится окно «Что нового». Все изменения: Что нового.

При обновлении данные не теряются. Старую версию нельзя установить поверх новой.
