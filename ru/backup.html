Бэкап и восстановление ​

Программа сама делает бэкап ​

  • Регулярно (обычно раз в 20 часов) и при закрытии.
  • Отдельный бэкап перед обновлением и перед восстановлением.
  • Если подключён Telegram — раз в день на телефон.

Раз в неделю: USB ​

Вставьте USB-флешку → Бэкап → Скопировать последний бэкап на диск …. Не храните флешку рядом с компьютером.

Код восстановления ​

Бэкап → Код восстановления → ваш пароль. Его нужно записать на бумаге — если компьютер сломается, без него данные не вернуть.

Восстановить бэкап ​

Если что-то случайно испортилось:

  • в списке рядом с бэкапом Восстановить → пароль админа.

Восстановление из файла ​

Файл с USB или скачанный из Telegram: Восстановить из файла → выберите файл → пароль админа.

  • Если из Telegram пришли части (.001, .002…) — скачайте все и выберите все вместе (с Ctrl).
  • Если файл с другого компьютера — введите и код восстановления той установки.

После восстановления все входят заново. Состояние до восстановления остаётся как бэкап «Перед восстановлением» — ничего не теряется.

Экран восстановления ​

Если база удалена, повреждена, потерян ключ или осталась старая версия программы, вместо обычного экрана открывается экран Восстановление. Причина написана вверху.

  1. Введите код восстановления (с бумаги).
  2. Выберите: Восстановить этот бэкап, Восстановить из файла (USB, Telegram), Восстановить ключ или Проверить снова.
  3. Начать с пустой базы — только если бэкапов нет совсем.

Без кода восстановления на этом экране ничего сделать нельзя — данные защищены. Если написано «Старая версия программы» — просто установите последнюю версию.

«ВНИМАНИЕ: база заменена старой копией!» ​

Пока программа была закрыта, кто-то заменил файл данных старой копией — продажи за это время могли пропасть. Проверьте бэкапы в Telegram и на USB, при необходимости восстановите более новый, затем Понятно.

Компьютер сломался ​

Установите Kassa на новом компьютере → при первом запуске создайте временного админа → Бэкап → Восстановить из файла (файл с USB или из Telegram) + код восстановления старой установки. Старые пользователи, товары и настройки вернутся.
