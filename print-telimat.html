Kassir üçün qısa vərəq ​

Bu səhifəni çap edib kassanın yanına qoyun

PDF yüklə bölməsində "Kassir üçün qısa vərəq" — bir A4 vərəq.

1. Proqramı açmaq ​

İş masasında yaşıl Kassa ikonu → adınızı seçin → parol → Daxil ol.

2. Satış ​

  1. Malın barkodunu skan edin — mal səbətə düşür ("bip" səsi). Eyni malı yenidən skan etsəniz, sayı artır.
  2. Barkodu yoxdursa — yuxarıdakı sahəyə adını yazın və siyahıdan seçin.
  3. Çəki ilə satılan mal (kq) — çəkini yazın, məs. 0,750.
  4. Sayı dəyişmək: − / +. Səhv malı ✕ ilə silin.

3. Ödəniş ​

DüyməNə vaxt
Nağd və ya F2Müştərinin verdiyi pulu yazın (və ya 5 ₼, 10 ₼… düyməsi). Proqram qaytarılacaq pulu göstərir. Pul dəqiqdirsə — boş saxlayın.
Kart və ya F3Əvvəl bank terminalında ödənişin keçdiyinə baxın, sonra təsdiqləyin.

Sonra Satışı tamamla və ya Enter.

4. Qəbz ​

  • Qəbz printeri qoşulubsa, qəbz özü çıxır.
  • Yoxdursa, satışdan sonra çıxan yaşıl yazıda "Qəbz" düyməsini basın.

5. Səslər ​

SəsMənası
Qısa "bip"Mal tapıldı
Alçaq səsMal tapılmadı — admin malı sistemə əlavə etməlidir

6. Bağlamaq ​

Pəncərənin sağ üstündəki ✕. Proqram özü backup edib bağlanır. Bir müddət toxunulmasa, proqram sizi çıxarır — yenidən parol yazın.

Bir şey alınmasa ​

  • Ekran ağ qaldı / "xəta" — Yenidən yüklə və ya pəncərəni bağlayıb yenidən açın. Satışlar itmir.
  • Parolu unutdunuz — admin "İstifadəçilər" bölməsində yeniləyir.
  • Başqa hər şey — Bir şey alınmasa.

Quraşdırma və ilk açılış ​

Bu səhifə proqramı quraşdıran adam üçündür (adətən mağazanın sahibi). Bir dəfə edilir.

1. Proqramı endirmək ​

Ən son versiya: Kassa-Setup — endir (Kassa-Setup-….exe faylı).

2. Quraşdırmaq ​

  1. Kassa-Setup-….exe faylını açın.
  2. Windows "naməlum proqram" desə: "Daha çox" → "Yenə də işlət".
  3. Dili seçin (Azərbaycanca, Русский, English).
  4. Quraşdırma növünü seçin:
    • "Bütün istifadəçilər üçün" (mağaza üçün tövsiyə olunur) — Windows admin parolu soruşulur. Proqram qorunan rejimdə işləyir: kassir proqramı və məlumatları silə bilmir. Bax Windows hesabları.
    • "Yalnız mənim üçün" — admin parolu lazım deyil. Sınamaq və ya ev kompüteri üçün.
  5. İrəli → Quraşdır → Bitir. İş masasında yaşıl Kassa ikonu yaranır.

3. İlk açılış ​

  1. Quraşdırma parolu — proqramı sizə verən şəxsdən alın. Yalnız ilk dəfə soruşulur.
  2. Dili, mağazanın adını, öz adınızı və parolunuzu yazın (ən az 8 simvol, hərf və rəqəm). Siz mağazanın admini olursunuz.
  3. Quraşdır.

4. Bərpa kodu — mütləq kağıza yazın ​

Quraşdırmadan sonra ekranda bərpa kodu çıxır.

  • Onu kağıza yazın və evdə və ya seyfdə saxlayın. Kompüterdə fayl kimi saxlamayın.
  • Kompüter xarab olsa və ya oğurlansa, məlumatları yalnız bu kodla qaytarmaq olar.
  • Sonra da görmək olar: Backup → Bərpa kodu → parolunuz.

"Kodu yazdım" qutusunu işarələyin → Davam et.

5. Windows hesabları: kassir üçün ayrıca hesab ​

Ən etibarlı qoruma ("Bütün istifadəçilər üçün" quraşdırılanda):

  1. Sahib üçün Windows-da parollu admin hesabı — Kassa-nı o quraşdırır və yeniləyir.
  2. Kassir üçün standart (admin olmayan) hesab: Parametrlər → Hesablar → Digər istifadəçilər → Hesab əlavə et → hesab növü "Standart istifadəçi".
  3. Kompüter hər gün kassirin hesabında açılır. Kassa orada da işləyir, amma kassir proqramı və məlumat fayllarını silə və ya dəyişə bilmir.
  4. Kassa-ya hər kəs öz Kassa adı və parolu ilə daxil olur (bunlar Windows parolundan ayrıdır).

Bu rejimdə pəncərəni bağlamaq proqramı tam dayandırmır — arxa planda işləyir (Telegram hesabatı, backup). Bu normaldır.

Skaner necə işləyir

Barkod skaneri klaviatura kimidir: rəqəmləri çox sürətlə "yazır" və sonda Enter basır. Proqram bunu insan yazısından sürətə görə ayırır, ona görə skan edərkən heç bir sahəyə basmaq lazım deyil.

Satış ​

Malı səbətə əlavə etmək ​

  • Skan edin — mal səbətə düşür, qısa "bip" səsi gəlir. Eyni malı yenidən skan etsəniz, sayı artır.
  • Barkodu yoxdursa — yuxarıdakı sahəyə adını yazın və siyahıdan seçin.
  • Çəki ilə satılan mal (kq) — proqram çəkini soruşur: məs. 0,750 (750 qram).

Alçaq səs və "Məhsul tapılmadı" — bu mal sistemdə yoxdur. Admin onu əlavə etməlidir. Admin özü skan edirsə, dərhal "Yeni məhsul" pəncərəsi açılır.

Səbəti düzəltmək ​

  • Sayı dəyişmək: − / + və ya rəqəmin üstünə basın.
  • Səhv malı silmək: sətrin sonundakı ✕.
  • Hamısını silmək: Səbəti təmizlə.

Ödəniş ​

Nağd (F2)Müştərinin verdiyi pulu yazın və ya hazır düyməni seçin. Proqram qaytarılacaq pulu göstərir. Pul dəqiqdirsə — sahəni boş saxlayın.
Kart (F3)Əvvəl bank terminalında ödənişin keçdiyinə baxın, sonra təsdiqləyin.

Satışı tamamla və ya Enter. Ekranda "Satış #… — … ₼" yazısı çıxır.

Qəbz ​

  • Qəbz printeri seçilib və "Satış bitəndə qəbz özü çap olunsun" yanılıdırsa — qəbz özü çıxır.
  • Yoxdursa — yaşıl yazıdakı "Qəbz" düyməsi.
  • Köhnə satışın qəbzi: Satışlar → satış → Qəbzi çap et.
  • Nağd satışda kassa qutusu (qoşulubsa) özü açılır.

Qalıq mənfiyə düşsə

Sistemdə olduğundan çox satılıbsa, satış yenə keçir, amma xəbərdarlıq çıxır — demək, mal qəbulu edilməyib. Admin mal qəbulunu etməlidir.

Mallar, barkod və etiket ​

Yalnız admin.

Yeni mal ​

Məhsullar → Yeni məhsul:

SahəNə yazmaq
BarkodMalın barkodunu skan edin
AdKassirin və qəbzin görəcəyi ad
VahidƏdəd və ya kq (çəki ilə)
Satış qiymətiMüştərinin ödədiyi qiymət

Satış və ya mal qəbulu zamanı sistemdə olmayan barkod skan olunsa, bu pəncərə özü açılır.

Barkodu olmayan mal ​

Çörək, göyərti, öz məhsulunuz: Barkod yarat düyməsi → proqram mağaza üçün barkod verir (29 ilə başlayır). Sonra etiketini çap edib mala yapışdırın.

Qiyməti dəyişmək ​

Malın sətrində ✏️ → yeni qiymət → Yadda saxla. Dəyişiklik jurnala yazılır. Malı satışdan çıxarmaq: Aktiv işarəsini götürün (mal silinmir, tarixçəsi qalır).

Etiket çapı ​

  1. Məhsullar → lazımi malların qutucuqlarını işarələyin (və ya bir malın sətrində 🏷).
  2. Etiket çap et → növ:
    • A4 vərəq — 24 etiket (70×37 mm) və ya 40 etiket;
    • etiket printeri rulonu — 58×40, 50×30, 40×30 və ya 30×20 mm (rulondakı etiketin ölçüsü).
  3. Hər maldan neçə ədəd: +.
  4. Çap et. Etiket printeri seçilibsə, düymədə printerin adı yazılır — etiketlər pəncərəsiz çıxır.

Çap pəncərəsi ilə (printer seçilməyibsə), ilk dəfə

Miqyas: 100% (Faktiki ölçü) və Kənar boşluqlar: Yoxdur seçin. Əvvəlcə adi kağıza sınaq çapı edin.

Etiket çıxandan sonra barkodunu skanerlə yoxlayın — "bip" olmalıdır.

Mal qəbulu ​

Yalnız admin. Mal gələndə qalığı artırmaq üçün.

  1. Mal qəbulu bölməsi → gələn malları skan edin (və ya adını yazın).
  2. Hər malın sayını və alış qiymətini yazın.
  3. İstəsəniz təchizatçının adını və qeyd yazın.
  4. Qəbulu təsdiqlə → Təsdiqlə.

Qalıq dərhal artır. Sistemdə olmayan mal skan olunsa, "Yeni məhsul" pəncərəsi açılır.

Qəbul sənədi ​

Aşağıdakı "Son 30 günün mal qəbulları" siyahısından qəbulu açın → Sənədi çap et (imza yerləri ilə — təchizatçı və qəbul edən).

Qəbulu səhv etdinizsə

Qəbul silinmir (anbarın tarixçəsi pozulmasın). Səhv sayı düzəltmək üçün fərqi yeni qəbulla əlavə edin; artıq yazılıbsa — texniki şəxsə müraciət edin.

Qalıqlar və hesabat ​

Qalıqlar ​

Hər maldan nə qədər qalıb. Az qalanlar sekmesi — sifariş siyahısı kimi çap edin.

Hesabat (admin) ​

Seçilmiş günlər üçün: dövriyyə, mənfəət, nağd və kart, ən çox satılanlar, bitmək üzrə olanlar.

"Nağd" — kassada olmalı olan pul. Gün sonunda kassanı sayıb müqayisə edin.

Çap və Excel ​

Hər səhifədə:

  • Çap et — printerə və ya "PDF kimi saxla";
  • Excel — fayl "Endirilənlər" qovluğuna düşür.

Siyahı çox uzundursa, ekranda ilk 300 sətir görünür — aşağıda "Daha … göstər". Çapa və Excel-ə hamısı düşür.

Satışlar və ləğv ​

  • Satışlar → tarix seçin → satışa basın → detallar.
  • Qəbzi çap et — köhnə satışın qəbzi.
  • Kassir yalnız öz satışlarını görür.

Satışı ləğv etmək (yalnız admin) ​

Səhv satış → Satışı ləğv et → səbəb yazın (məcburidir).

  • Satış silinmir — "Ləğv edilib" kimi qalır, kimin və nə vaxt ləğv etdiyi yazılır.
  • Mallar qalığa qayıdır.
  • Gündəlik Telegram hesabatında ləğvlər ayrıca göstərilir.

İstifadəçilər ​

Yalnız admin.

Yeni istifadəçi → ad, rol, parol.

Parol ​

  • Parolu unudanın parolunu admin Parol düyməsi ilə yeniləyir.
  • Hər kəs öz parolunu dəyişə bilər: sol aşağıda adınıza basın → Parolu dəyiş.

Blok ​

Kimsə parolu 10 dəfə səhv yazsa, 1 dəqiqə gözləməlidir (3-cü səhvdən sonra neçə cəhd qaldığını görür). Admin Bloku aç ilə dərhal aça bilər. Sayı və müddəti Ayarlarda dəyişmək olar.

İşdən çıxan işçi ​

Deaktiv et — istifadəçi silinmir, keçmiş satışları qalır, amma daxil ola bilmir.

Məşq rejimi: yeni kassiri öyrətmək ​

Kömək → Məşq rejimi (kassir öyrənir) → müddət (15 dəq.–2 saat) → Məşqə başla.

  • Satış ekranı tam işləyir: skan, nağd/kart, qaytarılacaq pul. Amma satışlar yazılmır və qalıq dəyişmir.
  • Bütün ekranlarda narıncı "MƏŞQ REJİMİ" zolağı və qalan vaxt görünür.
  • Bu müddətdə real satış etmək olmur — məşqi müştərisiz vaxtda edin.
  • Vaxt bitəndə rejim özü bağlanır; əvvəl bitirmək üçün Məşqi bitir.
  • Yalnız admin aça bilər (kassir yox). Açılış və bağlanış jurnala və gündəlik Telegram hesabatına yazılır.

Ayarlar və dil ​

Yalnız admin. Dəyişiklikdən sonra yuxarıdakı Yadda saxla düyməsini basın (Telegram tokeni və çat istisnadır — onlar özü saxlanılır). Hər dəyişiklik jurnala yazılır.

Sol aşağıda adınıza basın → Dil → Azərbaycanca / Русский / English (və ya "Mağazanın dili"). Yalnız sizin üçün dəyişir — kassir öz dilini ayrıca seçə bilər.

Çek və etiket printeri ​

Bir termal printer (məs. Xprinter XP-365B) həm qəbz, həm barkod etiketi çap edə bilər.

Qoşmaq ​

  1. Printeri USB ilə qoşun və onun Windows drayverini quraşdırın (qutudakı disk və ya istehsalçının saytı). Windows-un "Printerlər" siyahısında görünməlidir.
  2. Kassa → Ayarlar → Printerlər:
    • Qəbz printeri və Etiket (barkod) printeri — siyahıdan cihazı seçin (eyni cihaz ola bilər);
    • Etiket ölçüsü (Satış və çap kartında) — rulondakı etiketin ölçüsü (məs. 40×30);
    • istəsəniz: Satış bitəndə qəbz özü çap olunsun, Nağd satışda kassa qutusunu aç.
  3. Yadda saxla → Sınaq qəbzi və Sınaq etiketi.
  4. Sınaq etiketinin barkodunu skanerlə oxudun — "bip" olmalıdır.

Necə işləyir ​

  • Printer seçilibsə — qəbz və etiket pəncərəsiz, birbaşa gedir.
  • Printer seçilməyibsə ("Çap pəncərəsi") — hər çapda Windows-un çap pəncərəsi açılır, istənilən printerlə işləyir.
  • Printer sönülüdürsə və ya kağız bitibsə — xəta çıxır və "Çap pəncərəsi ilə" təklif olunur. Qəbz itmir.

Problemlər ​

SimptomNə etmək
"Seçilmiş printer tapılmadı"Printer qoşulub və yanılıdır? Ayarlarda yenidən seçin.
Etiket iki etiketə bölünür / boşluq qalır"Etiket ölçüsü" rulonla eyni olmalıdır. Printerin sensorunu kalibrləyin (Xprinter: FEED düyməsini basılı saxlayıb yandırın).
Barkod oxunmurTermal başlığı təmizləyin; 30×20 etiketdə barkod kiçikdir — 40×30 daha yaxşıdır.
Kassa qutusu açılmırQutu qəbz printerinin RJ11 yuvasına qoşulmalıdır (bəzi etiket printerlərində bu yuva yoxdur). "Qutunu aç" sınağına baxın.

Telegram: gündəlik hesabat və backup ​

Hər axşam sahibin telefonuna qısa hesabat (satış, dövriyyə, nağd və kart, ləğvlər — kim etdi, bitmək üzrə olan mallar) və şifrəli backup gəlir. Kompüter oğurlansa və ya xarab olsa da, Telegram-dakı nüsxə qalır.

Mesaj gəlmirsə — bu özü xəbərdarlıqdır: nəsə yolunda deyil.

Qoşmaq (bir dəfə, internet lazımdır) ​

  1. Telefonda Telegram-da @BotFather-ı tapın → /newbot → bota ad verin (məs. "Mağaza Kassa") və istifadəçi adı (sonu bot ilə bitməlidir).
  2. BotFather uzun bir token verir (123456789:AA…). Onu kopyalayın.
  3. Kassa → Ayarlar → Telegram → Bot tokeni sahəsinə yapışdırın.
  4. Telegram-da öz botunuzu tapın və ona /start yazın.
    • Qrupa göndərmək üçün: botu qrupa əlavə edin və qrupda /start@botun_adı yazın (məs. /start@magaza_kassa_bot). Adi mesaj kifayət etmir — Telegram qrupdakı adi mesajları bota göstərmir.
  5. Kassa-da Çatı tap. Bir neçə çat tapılsa (şəxsi və qrup) — siyahıdan seçin. Seçim özü yadda saxlanılır.
  6. Hesabat vaxtını seçin (məs. 21:00) → Sınaq mesajı. Telefona mesaj gəlməlidir.

Sonra ​

  • Hesabat hər gün seçilmiş vaxtda. Proqram o vaxtdan əvvəl bağlanıbsa — ertəsi gün "gecikmiş hesabat".
  • Backup gündə bir dəfə. Böyük bazada fayl hissələrə bölünür (.001, .002…).
  • İnternet yoxdursa, 15 dəqiqədən bir yenidən cəhd. Son göndərişin vaxtı və nəticəsi Ayarlarda görünür.
  • Saxlanmış token ekranda göstərilmir (sahə boşdur, "Saxlanılıb" yazılır). Kimsə tokeni bilsə — BotFather-da /revoke.

Sarı xəbərdarlıq "Telegram-a backup getmir"

2 gündən çoxdur heç nə gedə bilmir. Səbəb xəbərdarlıqda yazılır. Yoxlayın: internet var? Bot silinməyib? Ayarlar → Telegram → Sınaq mesajı.

Telegram-dakı backup-ı necə bərpa etmək: Backup və bərpa.

Backup və bərpa ​

Proqram özü backup edir ​

  • Mütəmadi (adətən 20 saatdan bir) və bağlananda.
  • Yeniləmədən və bərpadan əvvəl ayrıca backup.
  • Telegram qoşulubsa — gündə bir dəfə telefona.

Həftədə bir dəfə: USB ​

USB fləşi taxın → Backup → Ən son backup-ı … diskinə köçür. USB-ni kompüterin yanında saxlamayın.

Bərpa kodu ​

Backup → Bərpa kodu → parolunuz. Kağıza yazılmalıdır — kompüter xarab olsa, onsuz məlumat qaytarılmır.

Backup-ı bərpa etmək ​

Səhvən nəsə pozulubsa:

  • siyahıda backup-ın yanında Bərpa et → admin parolu.

Fayldan bərpa ​

USB-dəki və ya Telegram-dan yüklənmiş faylı: Fayldan bərpa → faylı seçin → admin parolu.

  • Telegram-dan hissələr gəlibsə (.001, .002…) — hamısını yükləyin və hamısını birlikdə seçin (Ctrl ilə).
  • Fayl başqa kompüterdəndirsə — həmin quraşdırmanın bərpa kodunu da yazın.

Bərpadan sonra hamı yenidən daxil olur. Bərpadan əvvəlki vəziyyət "Bərpadan əvvəl" backup-ı kimi qalır — heç nə itmir.

Bərpa ekranı ​

Baza silinsə, zədələnsə, açar itsə və ya proqramın köhnə versiyası qalıbsa, adi ekran əvəzinə Bərpa ekranı açılır. Səbəb yuxarıda yazılır.

  1. Bərpa kodunu (kağızdakı) yazın.
  2. Seçin: Bu backup-ı bərpa et, Fayldan bərpa (USB, Telegram), Açarı bərpa et və ya Yenidən yoxla.
  3. Boş bazadan başla — yalnız heç bir backup yoxdursa.

Bərpa kodu olmadan bu ekranda heç nə etmək olmur — məlumatlar qorunur. "Proqramın köhnə versiyası" yazılıbsa — sadəcə ən son versiyanı quraşdırın.

"DİQQƏT: baza köhnə nüsxə ilə əvəz edilib!" ​

Proqram bağlı ikən kimsə məlumat faylını köhnə nüsxə ilə dəyişib — arada edilmiş satışlar itmiş ola bilər. Telegram və USB-dəki backup-ları yoxlayın, lazımdırsa daha yenisini bərpa edin, sonra Gördüm.

Kompüter xarab oldu ​

Yeni kompüterdə Kassa-nı quraşdırın → ilk açılışda müvəqqəti admin yaradın → Backup → Fayldan bərpa (USB və ya Telegram faylı) + köhnə quraşdırmanın bərpa kodu. Köhnə istifadəçilər, mallar və ayarlar qayıdır.

Yeniləmə ​

Proqram yalnız rəsmi (imzalı) Kassa yeniləmələrini qəbul edir — saxta və ya dəyişdirilmiş fayl quraşdırılmır.

İnternetdən ​

Yeni versiya çıxanda adminə "Kassa-nın yeni versiyası var" yazısı görünür → Bax (və ya Ayarlar → Yeniləmə) → Yenilə → admin parolu.

Proqram əvvəlcə backup alır, bağlanır və bir neçə saniyəyə yeni versiya ilə özü açılır. Satışın ortasında heç nə özbaşına quraşdırılmır — yalnız siz "Yenilə" basanda.

Fayldan (internet yoxdursa) ​

Developerin göndərdiyi Kassa-Update-….kassa faylını kompüterə köçürün (USB, WhatsApp) → Ayarlar → Yeniləmə → Fayldan yenilə (.kassa) → faylı seçin → "Fayl yoxlanıldı: rəsmi Kassa …" → Yenilə.

Sonra ​

Bir dəfə "Nə dəyişib" pəncərəsi çıxır. Bütün dəyişikliklər: Nə dəyişib.

Yeniləmədə məlumatlar itmir. Köhnə versiyanı yenisinin üstünə quraşdırmaq olmur.
