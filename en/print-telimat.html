Cashier quick guide ​

Print this page and keep it next to the till

The Download PDF page has the "Cashier quick guide" — one A4 sheet.

1. Opening the program ​

Green Kassa icon on the desktop → choose your name → password → Log in.

2. Selling ​

  1. Scan the product's barcode — the product goes into the cart (a "beep"). Scan the same product again and the quantity goes up.
  2. No barcode? Type the name in the box at the top and choose it from the list.
  3. Products sold by weight (kg) — enter the weight, e.g. 0.750.
  4. Change the quantity: − / +. Remove a wrong product with ✕.

3. Payment ​

ButtonWhen
Cash or F2Enter the money the customer gave you (or press 5 ₼, 10 ₼…). The program shows the change due. If the amount is exact, leave it empty.
Card or F3First check that the payment went through on the bank terminal, then confirm.

Then Complete sale or Enter.

4. Receipt ​

  • If a receipt printer is connected, the receipt prints by itself.
  • If not, press the "Receipt" button in the green message after the sale.

5. Sounds ​

SoundMeaning
Short "beep"Product found
Low toneProduct not found — the admin must add the product to the system

6. Closing ​

The ✕ in the top right corner of the window. The program makes a backup and closes. If nobody touches it for a while, the program logs you out — enter your password again.

If something goes wrong ​

  • Blank white screen / "error" — Reload, or close the window and open it again. Sales are not lost.
  • Forgot your password — the admin sets a new one in "Users".
  • Anything else — If something goes wrong.

Installation and first launch ​

This page is for the person who installs the program (usually the shop owner). It is done once.

1. Download the program ​

Latest version: Kassa-Setup — download (the Kassa-Setup-….exe file).

2. Install ​

  1. Open the Kassa-Setup-….exe file.
  2. If Windows says "unrecognized app": "More info" → "Run anyway".
  3. Choose the language (Azərbaycanca, Русский, English).
  4. Choose the installation mode:
    • "Install for all users" (recommended for a shop) — Windows asks for the administrator password. The program runs in protected mode: the cashier cannot remove the program or the data. See Windows accounts.
    • "Install for me only" — no administrator password needed. For trying it out or a home computer.
  5. Next → Install → Finish. A green Kassa icon appears on the desktop.

3. First launch ​

  1. Installation password — get it from the person who gave you the program. It is asked only the first time.
  2. Choose the language, enter the shop name, your name and your password (at least 8 characters, letters and digits). You become the shop's admin.
  3. Set up.

4. Recovery code — write it on paper ​

After setup, a recovery code appears on the screen.

  • Write it on paper and keep it at home or in a safe. Do not store it as a file on the computer.
  • If the computer breaks or is stolen, the data can be brought back only with this code.
  • You can see it later too: Backup → Recovery code → your password.

Tick "I have written down the code…" → Continue.

5. Windows accounts: a separate account for the cashier ​

The safest setup (when installed "for all users"):

  1. For the owner: a Windows administrator account with a password — they install and update Kassa from it.
  2. For the cashier: a standard (non-administrator) account: Settings → Accounts → Other users → Add account → account type "Standard User".
  3. Every day the computer is used in the cashier's account. Kassa works there too, but the cashier cannot delete or change the program or the data files.
  4. Everyone logs in to Kassa with their own Kassa name and password (separate from the Windows password).

In this mode closing the window does not stop the program completely — it keeps running in the background (Telegram report, backup). This is normal.

How the scanner works

A barcode scanner works like a keyboard: it "types" the digits very fast and presses Enter at the end. The program tells it apart from a person by the speed, so you don't need to click any field when scanning.

Selling ​

Adding a product to the cart ​

  • Scan it — the product goes into the cart with a short "beep". Scan the same product again and the quantity goes up.
  • No barcode — type the name in the box at the top and choose it from the list.
  • Products sold by weight (kg) — the program asks for the weight: e.g. 0.750 (750 grams).

A low tone and "Product not found" — this product is not in the system. The admin must add it. If the admin is scanning, the "New product" window opens right away.

Fixing the cart ​

  • Change the quantity: − / + or click the number.
  • Remove a wrong product: the ✕ at the end of the line.
  • Remove everything: Clear cart.

Payment ​

Cash (F2)Enter the money the customer gave you or pick a ready button. The program shows the change due. If the amount is exact, leave the box empty.
Card (F3)First check that the payment went through on the bank terminal, then confirm.

Complete sale or Enter. The message "Sale #… — … ₼" appears on the screen.

Receipt ​

  • If a receipt printer is selected and "Print the receipt automatically after a sale" is on, the receipt prints by itself.
  • If not, use the "Receipt" button in the green message.
  • Receipt for an old sale: Sales → the sale → Print receipt.
  • For cash sales the cash drawer (if connected) opens by itself.

If stock goes negative

If more was sold than the system has, the sale still goes through, but a warning appears — it means the goods receiving was not entered. The admin must do the goods receiving.

Products, barcodes and labels ​

Admin only.

New product ​

Products → New product:

FieldWhat to enter
BarcodeScan the product's barcode
NameThe name the cashier and the receipt will show
UnitPiece or Kilogram (by weight)
Sale priceThe price the customer pays
Cost priceThe price you paid (for profit calculation; the cashier does not see it)
Minimum stockBelow this, the "Low" warning appears

If a barcode that is not in the system is scanned during a sale or receiving, this window opens by itself.

Products without a barcode ​

Bread, herbs, your own products: the Generate barcode button → the program gives an in-store barcode (starts with 29). Then print its label and stick it on the product.

Changing the price ​

✏️ on the product's line → new price → Save. The change is written to the log. To stop selling a product: untick Active (the product is not deleted, its history stays).

Printing labels ​

  1. Products → tick the products you need (or 🏷 on a single product's line).
  2. Print labels → type:
    • A4 sheet — 24 labels (70×37 mm) or 40 labels;
    • label printer roll — 58×40, 50×30, 40×30 or 30×20 mm (the size of the label on the roll).
  3. How many of each product: +.
  4. Print. If a label printer is selected, the button shows the printer's name — labels print without a print dialog.

With the print dialog (no printer selected), the first time

Choose Scale: 100% (Actual size) and Margins: None. Do a test print on plain paper first.

After the label prints, check its barcode with the scanner — you should hear a "beep".

Receiving goods ​

Admin only. To increase stock when goods arrive.

  1. The Receiving section → scan the incoming goods (or type the name).
  2. Enter the quantity and cost price for each product.
  3. Optionally enter the supplier's name and a note.
  4. Confirm receiving → Confirm.

Stock goes up immediately. If a product that is not in the system is scanned, the "New product" window opens.

Receiving note ​

Open the receiving in the "Receivings in the last 30 days" list below → Print document (with signature lines for the supplier and the person receiving).

If you made a mistake in a receiving

A receiving is not deleted (so the stock history stays intact). To fix a wrong quantity, add the difference with a new receiving; if too much was entered, contact your technical person.

Stock and reports ​

Stock ​

How much of each product is left. The Low tab — print it as an order list.

Report (admin) ​

For the selected days: revenue, profit, cash and card, best sellers, products running low.

"Cash" — the money that should be in the till. At the end of the day, count the till and compare.

Printing and Excel ​

On every page:

  • Print — to a printer or "Save as PDF";
  • Excel — the file goes to the "Downloads" folder.

If the list is very long, the screen shows the first 300 lines — "Show … more" at the bottom. Printing and Excel include everything.

Sales and voiding ​

  • Sales → choose the date → click a sale → details.
  • Print receipt — receipt for an old sale.
  • A cashier sees only their own sales.

Voiding a sale (admin only) ​

Wrong sale → Void sale → enter the reason (required).

  • The sale is not deleted — it stays as "Voided", with who voided it and when.
  • The products go back into stock.
  • The daily Telegram report lists voids separately.

Users ​

Admin only.

New user ​

New user → name, role, password.

RoleWhat they can doPassword
CashierSell, view stock and their own salesat least 4 characters (e.g. 4 digits)
AdminEverything: products, prices, receiving, voids, reports, users, settingsat least 8 characters, letters and digits

Password ​

  • If someone forgets their password, the admin sets a new one with the Password button.
  • Everyone can change their own password: click your name at the bottom left → Change password.

Lock ​

If someone enters a wrong password 10 times, they must wait 1 minute (after the 3rd mistake they see how many attempts are left). The admin can unlock them right away with Unlock. The number and the time can be changed in Settings.

An employee leaves ​

Deactivate — the user is not deleted and their past sales stay, but they cannot log in.

Training mode: teaching a new cashier ​

Help → Training mode (cashier practice) → duration (15 min–2 hours) → Start training.

  • The sale screen works fully: scanning, cash/card, change. But sales are not recorded and stock does not change.
  • An orange "TRAINING MODE" bar with the remaining time shows on every screen.
  • Real sales are not possible meanwhile — train when there are no customers.
  • The mode turns itself off when the time is up; to finish earlier — End training.
  • Only an admin can turn it on (not a cashier). Turning it on and off is recorded in the log and the daily Telegram report.

Everyone has their own language ​

Click your name at the bottom left → Language → Azərbaycanca / Русский / English (or "Shop language"). It changes only for you — the cashier can choose their own language separately.

Receipt and label printer ​

One thermal printer (e.g. Xprinter XP-365B) can print both receipts and barcode labels.

Connecting ​

  1. Connect the printer by USB and install its Windows driver (the disc in the box or the manufacturer's website). It must appear in the Windows "Printers" list.
  2. Kassa → Settings → Printers:
    • Receipt printer and Label (barcode) printer — choose the device from the list (it can be the same device);
    • Label size (in the Sales and printing card) — the size of the label on the roll (e.g. 40×30);
    • optionally: Print the receipt automatically after a sale, Open the cash drawer on cash payment.
  3. Save → Test receipt and Test label.
  4. Scan the barcode of the test label — you should hear a "beep".

How it works ​

  • If a printer is selected, receipts and labels go directly, without a print dialog.
  • If no printer is selected ("Print dialog"), the Windows print dialog opens every time; it works with any printer.
  • If the printer is off or out of paper, an error appears and "Use print dialog" is offered. The receipt is not lost.

Problems ​

SymptomWhat to do
"Selected printer not found"Is the printer connected and switched on? Select it again in Settings.
A label is split across two labels / blank space is left"Label size" must match the roll. Calibrate the printer's sensor (Xprinter: hold the FEED button while switching it on).
Barcode does not scanClean the thermal head; on a 30×20 label the barcode is small — 40×30 works better.
Cash drawer does not openThe drawer must be connected to the RJ11 port of the receipt printer (some label printers don't have this port). Try the "Open drawer" test.

Telegram: daily report and backup ​

Every evening a short report (sales, revenue, cash and card, voids — who did them, products running low) and an encrypted backup arrive on the owner's phone. Even if the computer is stolen or breaks, the copy in Telegram stays.

If no message arrives, that itself is a warning: something is wrong.

Connecting (once, internet needed) ​

  1. On your phone, find @BotFather in Telegram → /newbot → give the bot a name (e.g. "Shop Kassa") and a username (it must end with bot).
  2. BotFather gives you a long token (123456789:AA…). Copy it.
  3. Kassa → Settings → Telegram → paste it into the Bot token field.
  4. Find your bot in Telegram and send it /start.
    • To send to a group: add the bot to the group and send /start@your_bot_name in the group (e.g. /start@magaza_kassa_bot). An ordinary message is not enough — Telegram does not show ordinary group messages to bots.
  5. In Kassa, press Find chat. If several chats are found (private and group), choose one from the list. The choice is saved by itself.
  6. Choose the report time (e.g. 21:00) → Test message. A message should arrive on your phone.

After that ​

  • The report comes every day at the chosen time. If the program was closed before that time, a "late report" comes the next day.
  • Backup once a day. With a large database the file is split into parts (.001, .002…).
  • If there is no internet, it tries again every 15 minutes. The time and result of the last send are shown in Settings.
  • A saved token is not shown on the screen (the field is empty and says "Saved"). If someone learns the token — /revoke in BotFather.

Yellow warning "Backups are not reaching Telegram"

Nothing has been sent for more than 2 days. The reason is written in the warning. Check: is there internet? Was the bot deleted? Settings → Telegram → Test message.

How to restore a backup from Telegram: Backup and restore.

Backup and restore ​

The program backs up by itself ​

  • Regularly (usually every 20 hours) and when it closes.
  • A separate backup before an update and before a restore.
  • If Telegram is connected — once a day to your phone.

Once a week: USB ​

Insert a USB stick → Backup → Copy the latest backup to …. Do not keep the USB stick next to the computer.

Recovery code ​

Backup → Recovery code → your password. It must be written on paper — if the computer breaks, the data cannot be brought back without it.

Restoring a backup ​

If something got messed up by mistake:

  • in the list, Restore next to the backup → admin password.

Restore from file ​

A file from USB or downloaded from Telegram: Restore from file → choose the file → admin password.

  • If Telegram sent parts (.001, .002…) — download all of them and select all together (hold Ctrl).
  • If the file is from another computer, also enter that installation's recovery code.

After a restore everyone logs in again. The state before the restore is kept as a "Before restore" backup — nothing is lost.

Recovery screen ​

If the database is deleted or damaged, the key is lost, or an old version of the program is installed, the Recovery screen opens instead of the normal one. The reason is written at the top.

  1. Enter the recovery code (from the paper).
  2. Choose: Restore this backup, Restore from file (USB, Telegram), Recover key or Check again.
  3. Start with an empty database — only if there are no backups at all.

Nothing can be done on this screen without the recovery code — the data is protected. If it says "Old program version", just install the latest version.

"WARNING: the database was replaced with an old copy!" ​

While the program was closed, someone replaced the data file with an old copy — sales made in between may be missing. Check the backups in Telegram and on USB, restore a newer one if needed, then press Got it.

The computer broke ​

Install Kassa on the new computer → create a temporary admin on first launch → Backup → Restore from file (USB or Telegram file) + the old installation's recovery code. The old users, products and settings come back.

Updates ​

The program accepts only official (signed) Kassa updates — a fake or modified file will not be installed.

From the internet ​

When a new version is out, the admin sees "A new version of Kassa is available" → View (or Settings → Update) → Update → admin password.

The program first makes a backup, closes, and a few seconds later reopens by itself with the new version. Nothing installs by itself in the middle of a sale — only when you press "Update".

From a file (no internet) ​

Copy the Kassa-Update-….kassa file sent by the developer to the computer (USB, WhatsApp) → Settings → Update → Update from file (.kassa) → choose the file → "File verified: official Kassa …" → Update.

After that ​

A "What's new" window appears once. All changes: What's new.

Data is not lost during an update. An older version cannot be installed over a newer one.
