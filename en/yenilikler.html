What’s new ​

Changes by program version (newest first).

12.10.2026 ​

  • Help: the “Help” menu at the bottom left and “?” on every page — the user guide opens inside the program, offline (3 languages).
  • A printable cashier quick guide (PDF), keyboard shortcuts.
  • A “Getting started” checklist for the admin: shop details, first product, cashier, printer, Telegram.
  • Online guide, videos and PDFs: camalzadeh.github.io/kassa-docs
  • Training mode: a new cashier practises selling, sales are not recorded (admin only, time-limited).
  • Fixed: unsaved changes in Settings could disappear by themselves on a slow computer.

12.10.2026 ​

  • Telegram: after “Find chat” and a successful test message, the token and chat are saved automatically.
  • All settings (including defaults) are stored in the database — moving the database restores everything.
  • The new Kassa logo is shown everywhere instead of the old black icon.

11.10.2026 ​

  • Receipt and label printer (e.g. Xprinter): Settings → Printers. Receipts and labels print directly, without a print dialog; test printing.
  • The receipt can print automatically after a sale; otherwise use the “Receipt” button in the green notification.
  • The cash drawer can open on cash payment (if connected to the printer).
  • New label sizes: 50×30, 40×30, 30×20 mm.
  • Telegram: sending to a group fixed — when several chats are found, pick one from the list.
  • If Telegram has not worked for more than 2 days or the database is damaged, the admin sees a warning on the main screen.
  • Scans are no longer cut off (the barcode was split in two); the screen no longer freezes after a restore.
  • A new installation needs the installation password.

07.10.2026 ​

  • Languages: Azerbaijani, Russian, English. Each user can choose their own language in the menu.
  • New “Settings” section: shop details (shown on receipts), theme, text size, lock time, backups and more. All settings are stored in the database.
  • The database is backed up automatically before an update; an older program version will not open a newer database.
  • If the database is deleted or damaged, the program does not create a new one — a recovery screen opens (using the recovery code).
  • Backups can be restored from within the program, and the database can be moved to another disk.
  • If the database was replaced with an old copy while the program was closed, the admin is warned.
  • Updates are signed: the program installs only official versions (from the internet or from a file).
  • Telegram: a daily report and an encrypted backup to the owner’s phone.
