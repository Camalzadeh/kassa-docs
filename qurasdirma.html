Quraşdırma və ilk açılış ​

Bu səhifə proqramı quraşdıran adam üçündür (adətən mağazanın sahibi). Bir dəfə edilir.

1. Proqramı endirmək ​

Ən son versiya: Kassa-Setup — endir (Kassa-Setup-….exe faylı).

2. Quraşdırmaq ​

  1. Kassa-Setup-….exe faylını açın.
  2. Windows "naməlum proqram" desə: "Daha çox" → "Yenə də işlət".
  3. Dili seçin (Azərbaycanca, Русский, English).
  4. Quraşdırma növünü seçin:
    • "Bütün istifadəçilər üçün" (mağaza üçün tövsiyə olunur) — Windows admin parolu soruşulur. Proqram qorunan rejimdə işləyir: kassir proqramı və məlumatları silə bilmir. Bax Windows hesabları.
    • "Yalnız mənim üçün" — admin parolu lazım deyil. Sınamaq və ya ev kompüteri üçün.
  5. İrəli → Quraşdır → Bitir. İş masasında yaşıl Kassa ikonu yaranır.

3. İlk açılış ​

  1. Quraşdırma parolu — proqramı sizə verən şəxsdən alın. Yalnız ilk dəfə soruşulur.
  2. Dili, mağazanın adını, öz adınızı və parolunuzu yazın (ən az 8 simvol, hərf və rəqəm). Siz mağazanın admini olursunuz.
  3. Quraşdır.

4. Bərpa kodu — mütləq kağıza yazın ​

Quraşdırmadan sonra ekranda bərpa kodu çıxır.

  • Onu kağıza yazın və evdə və ya seyfdə saxlayın. Kompüterdə fayl kimi saxlamayın.
  • Kompüter xarab olsa və ya oğurlansa, məlumatları yalnız bu kodla qaytarmaq olar.
  • Sonra da görmək olar: Backup → Bərpa kodu → parolunuz.

"Kodu yazdım" qutusunu işarələyin → Davam et.

5. Windows hesabları: kassir üçün ayrıca hesab ​

Ən etibarlı qoruma ("Bütün istifadəçilər üçün" quraşdırılanda):

  1. Sahib üçün Windows-da parollu admin hesabı — Kassa-nı o quraşdırır və yeniləyir.
  2. Kassir üçün standart (admin olmayan) hesab: Parametrlər → Hesablar → Digər istifadəçilər → Hesab əlavə et → hesab növü "Standart istifadəçi".
  3. Kompüter hər gün kassirin hesabında açılır. Kassa orada da işləyir, amma kassir proqramı və məlumat fayllarını silə və ya dəyişə bilmir.
  4. Kassa-ya hər kəs öz Kassa adı və parolu ilə daxil olur (bunlar Windows parolundan ayrıdır).

Bu rejimdə pəncərəni bağlamaq proqramı tam dayandırmır — arxa planda işləyir (Telegram hesabatı, backup). Bu normaldır.
